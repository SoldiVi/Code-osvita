## Теоретичні відомості

Python вважається однією з найпростіших мов для вивчення. У порівнянні з іншими популярними об'єктноорієнтованими мовами, такими як C++ та Java, Python легко читати і розуміти, вона дозволяє швидко прототипувати та скорочує час розробки, має величезну кількість безкоштовних пакетів бібліотек.

Python – високорівнева мова програмування загального призначення, орієнтована на підвищення продуктивності розробника і читання коду.

Python підтримує декілька парадигм програмування, в тому числі:

* структурну
* об'єктно-орієнтовану
* функціональну
* імперативну
* аспектно-орієнтовану

На даний час існує дві гілки Python – 2.x та 3.x. Ми будемо працювати переважно з гілкою 3.x.

Існують різні інтерпретатори для мови Python. Офіційний інтерпретатор можна завантажити на сайті https://www.python.org.

## Основні принципи синтаксису мови Python

### 1. Кінець рядка є кінцем інструкції

```python
x = 5
print(2 + x)
```

### 2. Вкладені інструкції об'єднуються у блоки за величиною відступів

Відступ може бути будь-яким, головне, щоб в межах одного вкладеного блоку відступ був однаковий (рекомендується робити відступ 4 пробіли).

```python
if x == 10:
    print('yes')
```

### 3. Вкладені інструкції

Вкладені інструкції в Python записуються відповідно до одного і того ж шаблону, коли основна інструкція завершується двокрапкою, слідом за чим розташовується вкладений блок коду.

## Числа та операції над ними

Крім числових літералів, Python надає набір операцій для роботи з числовими об'єктами:

1. Оператори виразів: `+`, `-`, `*`, `/`, `>>`, `**`, `&` та інші
2. Вбудовані математичні функції: `pow`, `abs`, `round`, `int`, `hex`, `bin`
3. Допоміжні модулі: `random`, `math`

Для роботи з числами використовуються вирази, функції і модулі.

Дійсні числа мають методи:

* `as_integer_ratio`
* `is_integer_method`

Цілі числа мають атрибути, включаючи:

* `bit_length`

Приклади виразів:

* `X + Y`
* `X // Y`
* `X / Y`

Особливості:

* оператор `is` — перевірка ідентичності об'єктів
* `lambda` — створює неіменовані функції
* `!=` — перевірка нерівності

Операції:

* `%` — залишок від ділення
* `<<` — побітовий зсув вліво
* `&` — побітове "і"
* `//` — ділення з округленням вниз
* `/` — звичайне ділення

## Введення та виведення даних

Введення даних здійснюється за допомогою функції `input()`.

```python
x = input('Введіть x\n')  # дані мають тип рядка
y = input('Введіть y\n')

x = int(x)
y = int(y)

print(x + y)
```

### Завдання 1: Встановлення і налаштування середовища Python 3

1. З’ясуйте розрядність вашої операційної системи
2. Перейдіть на сайт https://www.python.org/downloads/
3. Оберіть версію Python
4. Завантажте файл `.exe` відповідної розрядності
5. Встановіть Python
6. Відзначте параметр **Install launcher for all users**
7. Встановіть прапорець **Add Python 3.x to PATH**
8. Оберіть **Customize installation**
9. Вкажіть каталог `C:\PythonX`
10. Перегляньте інструкцію встановлення
11. Перевірте встановлення

```bash
python --version
```

Очікуваний результат:

```
Python 3.9.0
```

12. Якщо результат є — Python встановлений успішно
