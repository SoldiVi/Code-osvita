## Теоретичні відомості

### Умовна інструкція `if`

Логіка висловлювань. Логічний тип даних. Величини можна порівнювати. Для цього в Python є такі операції порівняння:

* `>` більше
* `<` менше
* `>=` більше чи рівне
* `<=` менше чи рівне
* `==` дорівнює
* `!=` не дорівнює

**Наприклад:**

```
6>5 - True
7<1 - False
7==7 - True
7 != 7 - False
```

Python повертає значення `True` (Істина == 1), коли порівняння істинне, `False` (Хибність == 0) - в іншому випадку. True і False відносяться до логічного (булевого) типу даних `bool`.

В програмах часто використовують більш складні вирази - висловлювання. Істинність (`True`) або хибність (`False`) - це логічні значення висловлювання.

Python використовує три логічних оператора:

* `and` (І)
* `or` (АБО)
* `not` (НЕ)

**Наприклад:**

```
x = 8
у = 13
x == 8 and у < 15
x > 8 and у < 15
x != 0 or у > 15
x <0 or y >15
```

---

Для Python істинним або хибним може бути не тільки логічне висловлювання, а й об'єкт.

**Приклади:**

```
print('' and 2)
print('' or 2)
у = 6 > 8
print(6 > 8)
print(y)
print(not y)
print(not None)
print(not 2)
print(2 > 4 and 45 > 3)
```

---

### Робота операторів `and` та `or`

```
print(0 and 3)
print(5 and 4)
print(2 or 3)
print(None or 5)
print(None or 0)
```

## Інструкція `if`

Загальна форма:

```
if <test1>:
    <statements1>
elif <test2>:
    <statements2>
else:
    <statements3>
```

---

### Приклад

```
if 1:
    print('true')
```

```
x = int(input('Введіть х:'))
if x == 1:
    print('true')
else:
    print('false')
```

---

### Множинне розгалуження

```
x = 'killer rabbit'
if x == 'roger':
    print("how's jessica?")
elif x == 'bugs':
    print("what's up doc?")
else:
    print("Run away! Run away!")
```
